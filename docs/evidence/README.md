# Evidencia generada

Las pruebas ya no escriben aquí. Su evidencia va a `test-evidence/` (ignorada por Git y Docker) o a `COMMERCE_TEST_EVIDENCE_DIR`, mediante `tests/support/evidence.ts`; ver `docs/ci-cd.md`, «Evidencia de pruebas fuera del árbol versionado». Esta carpeta conserva sólo recibos revisados y versionados a propósito.

El repositorio público no contiene recibos operativos, capturas, logs ni respaldos históricos del sistema privado. Una prueba sintética no acredita un respaldo real ni una publicación. Los resultados nuevos deben revisarse antes de compartirlos.
